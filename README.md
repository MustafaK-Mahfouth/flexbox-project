# Flexbox Project

A responsive landing page built with HTML and Sass, using CSS Flexbox for the layout.

## Structure
- `index.html` - the page
- `sass/` - Sass source (compile to `css/style.css`)
- `css/` - compiled stylesheet
- `img/` - images

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.
